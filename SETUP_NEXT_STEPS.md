# Próximos pasos de integración

Este documento enumera únicamente la información necesaria para conectar servicios reales. No compartas claves privadas ni archivos de cuentas de servicio.

## GITHUB

Necesitas:
- URL o nombre definitivo del repositorio
- Organization/User propietario

## FIREBASE

Necesitas:
- configuración Web App de Firebase
- Project ID
- confirmación de Authentication Email/Password
- confirmación de Firestore creado

## VERCEL

Necesitas:
- confirmación de cuenta/equipo
- nombre del proyecto si quiero uno específico
